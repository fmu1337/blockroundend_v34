# No Round End — CS:S v34

Блокирует конец раунда.

**Author:** Danyas  
**SourceMod:** 1.4+

---

Скачай из [Releases](https://github.com/fmu1337/blockroundend_v34/releases) и распакуй в корень сервера (`cstrike/`):

```
addons/sourcemod/plugins/noroundend.smx
addons/sourcemod/gamedata/noroundend.games.txt
```

```
mp_ignore_round_win_conditions 1
```

(`sv_noroundend` — то же самое, квары синхронизированы)

Собран одним `spcomp` 1.4.2 — подходит и для новых SM (1.7 / 1.13).
